## Part 1: Static Assets Root Cause Analysis

### Root Cause
EB `config-deploy` lifecycle event wipes `/var/app/current/` and replaces it with the staging bundle. The `staticfiles/` directory is not included in the staging bundle and no `confighooks/postdeploy/` hook existed to recreate it. WhiteNoise was correctly configured but had no files to serve.

### Immediate Fix
Manual `collectstatic` executed on production:
```bash
cd /var/app/current && source /var/app/venv/staging-LQM1lest/bin/activate && python manage.py collectstatic --noinput
```
CSS/JS/images validated returning HTTP 200.

### Permanent Fix
Created `.platform/confighooks/postdeploy/00_collectstatic_current.sh` to run `collectstatic` during both `app-deploy` and `config-deploy` lifecycle events.
