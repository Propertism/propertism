## PHASE 1: INITIALIZE DATABASE (2-3 min)

```bash
# Connect
eb ssh

# Activate
source /var/app/venv/*/bin/activate
cd /var/app/current

# Check database config (optional)
python manage.py check

# Initialize database (10-15 sec)
python manage.py migrate --noinput

# Verify file exists
ls -lh /var/app/current/db.sqlite3
```

**Expected**: File appears at `/var/app/current/db.sqlite3` (~1.2 MB)
