# OAIDF - AntiGravity Memory

## Framework Identity
**OAIDF** (Open AI Development Framework) — A structured AI-driven development framework for building and managing AI-powered applications with governance, traceability, and modular design.

## Core Principles
1. **Governance-First** — Every decision is traceable via SCCB (Software Change Control Board).
2. **AI-Augmented** — Leverage prompts, agents, and automated workflows for development velocity.
3. **Separation of Concerns** — Clear boundaries between UI, Frontend, Backend, API, and Assets.
4. **Documentation-Driven** — No code without corresponding documentation.
5. **Research-Backed** — Architecture decisions rooted in 09-Research findings.

## Active Directories
- `00-Governance/` — Project charter, policies, compliance
- `01-SCCB/` — Change control board records and approvals
- `02-Architecture/` — System design, diagrams, ADRs
- `03-UI/` — Wireframes, design systems, UX specs
- `04-Frontend/` — Frontend source code (React/Next.js/Vue/etc.)
- `05-Backend/` — Backend source code (Node/Django/Go/etc.)
- `06-API/` — API specifications, contracts, OpenAPI docs
- `07-Prompts/` — AI prompts and prompt templates
- `08-Assets/` — Images, fonts, static resources
- `09-Research/` — Research findings, benchmarks, evaluations
- `10-Documentation/` — User guides, API docs, deployment guides
- `archive/` — Deprecated/archived components
- `backend/` — Alternative backend workspace (if needed)
- `frontend/` — Alternative frontend workspace (if needed)

## Session Rules
- All changes must be logged in 01-SCCB
- Architecture changes require ADR in 02-Architecture
- Prompts used must be saved to 07-Prompts
- Research must be filed in 09-Research before implementation
