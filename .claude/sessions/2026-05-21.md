### SCCB-PROP-DEPLOY-01 — Deploy Failure (CLOSED)

**Trigger:** Commit `963b8a6` caused EB deploy failure at `02_migrate`.

**Diagnosis path:**
1. First diagnosis: orphaned `_like` index (`properties_property_slug_f3b16024_like`) from failed prior deploy. Applied `RunSQL DROP IF EXISTS` patch → still failed.
2. Second diagnosis: crash in `schema.py __exit__` (deferred SQL phase) — confirmed patch shipped via commit hash in `eb-engine.log`. Root cause: both `AddField` (SlugField has `db_index=True` by default) and `AlterField` (adding `unique=True`) independently append `CREATE INDEX _like` to `deferred_sql`. Double-queue fails on any database state, including clean.

**Fix:** Split `0006_property_slug` into two migrations across a transaction boundary:
- `0006`: defensive `RunSQL DROP IF EXISTS` + `AddField(null=True)` only
- `0007`: `RunPython(populate_slugs)` + `AlterField(unique=True)`

Each migration runs its own `__exit__` with its own `deferred_sql` — no double-queue possible.

**Result:** `0006 OK` / `0007 OK` / 0 duplicate slugs / Green. Commit `9800e47`.
