# Session — 2026-05-15
**Project:** propertism.in

## What was done

- **Direct Google OAuth routing** — Added `SOCIALACCOUNT_LOGIN_ON_GET = True` to `realtor_project/settings.py`. Previously, clicking "Continue with Google" in the auth drawer landed on the intermediate login page before routing to Google's account chooser. Now it goes directly to Google — one fewer click for NRI users.

- **Fixed "Sign Up Closed" on OAuth callback** — `PropertismAccountAdapter.is_open_for_signup` returns `False` to block email/password signup, but allauth's social adapter chains to it, which also blocked new Google OAuth users. Added `is_open_for_signup` override to `AdminOnlySocialAccountAdapter` in `users/adapters.py` returning `True`, keeping Google registration open while email/password stays closed.

- **Admin session bleed (dev-only, no action)** — Admin login on `localhost:8001/admin/` was visible in the public nav. Confirmed this is a localhost artifact only; production (`admin.propertism.in` vs `propertism.in`) already isolates sessions by domain. No patch needed.
