## Technical Details

### Architecture Decision
- **Local Development**: SQLite (no DATABASE_URL in .env)
- **Production**: PostgreSQL RDS (DATABASE_URL set in EB)
- **Code**: Single `settings.py` handles both environments intelligently

### Deployment Pipeline
```
Git Push → GitHub Actions → EB Deploy
                              ↓
                    container_commands run:
                    1. collectstatic
                    2. migrate
                    3. seed_knowledge_hub_phase_a --publish
```

### Database Confirmation
```bash
# When DATABASE_URL is available (production):
$ python manage.py shell

```
